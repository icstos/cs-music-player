## 歌词面板：当前播放行垂直居中（TODO-Roadmap 2026-09-17）

- 需求：保持播放时，正在播放的歌词行停在歌词区**垂直中线**。
- 方案（`cs_music_player/ui.py` + `constants.py`）：
  - 丢弃 `ListView` 全量渲染，改为**窗口式渲染**：只画「当前行 ± 半屏」的行，
    用 `Column(alignment=CENTER)` 排布，当前行必然落在正中；首尾歌词用**等高空白占位行**补位。
  - **所有行等高**是前提（行高不齐就得逐行量像素）：`_lyric_row_height()` =
    `font_size * LYRIC_ROW_FACTOR(2.9) + LYRIC_ROW_GAP(14)`，装得下「放大一号的当前行」折两行。
  - 可见行数由**实测高度**推算：`Container(expand=True, on_size_change=…)` 拿到歌词区真实高度 →
    `_lyric_window_rows()` 取 `H // R` 并**去掉偶数**（偶数时当前行必然偏半行）→ `use_state` 缓存。
  - 窗口计算抽成纯函数 `_lyric_window(active, total, rows)`，已加单测 `tests/test_lyric_center.py`。
  - 顺带修掉 `LyricSettingsEntry` 上重复的 `@ft.component` 装饰器。
- 放弃的方案：`ListView` + `scroll_to`（只能对齐到顶部，且是 invoke_method 客户端往返；
  试算后发现用 padding 补偿会把边界行推到视口底部，见 skill 记录）。
- 真机验证（`.workbuddy/probe/`）：`flet-desktop-ui-probe` 技能探针，PrintWindow 截图 +
  纯 Python 墨迹带分析 → 760 高窗口 11 行时当前行偏移 -0.3px，420 高窗口 5 行时 -0.6px；
  首行/末行同样居中（±57.5px 等差数列对称）。证据图 `lyric_center_proof.png`、日志
  `lyric_center_probe.log`、探针脚本 `lyric_center_probe.py`。
- 环境：项目此前没有 `.venv`，`uv sync` 建好（flet 1.0.0 + flet-audio）；桌面端还需
  `uv pip install --python .venv/Scripts/python.exe flet-desktop==1.0.0`（pyproject 未声明）。
- 冒烟：真实 `main.py` 启动 14s 存活，无异常（只有 TextField 的既有 DeprecationWarning）。
- 已知取舍：歌词区不再可滚动，看不到未播放/已播放的远端歌词（窗口式居中的固有代价）。

- 需求原文：参考歌词微调功能配置，增加歌词字体大小配置（歌词同步、字体大小配置为两个入口）。
- 结论：**该功能早已实现并提交**（`38cf08a`，2026-08-27），只是当时把这条 TODO
  连同实现写进同一次提交、**漏勾选**，导致路线图上看像没做。代码位置：
  - `ui.py: LyricSettingsEntry` — 右上角两个互斥展开的胶囊入口（TUNE「同步」/ FORMAT_SIZE「15px」），
    各自展开一条工具条（同步：提前/延后 0.1s、1s + 恢复；字号：A- / A+ + 当前值 + 恢复默认）。
  - `app.py: lyric_font / adjust_lyric_font`、`store.py: load_lyric_font / save_lyric_font`
    （全局 `lyric_font` 键，11–24px，越界回退默认；同步偏移则是**按曲目**存 `lyric_offsets`）。
  - 本次未改业务代码，只补 README「歌词同步与字号」章节 + 勾选路线图。
- 真机核验（`.workbuddy/probe/lyric_settings_probe.py`，PrintWindow + 合成点击）：
  - 两入口可点开：点「15px」→ 字号条出现（入口区高 30→66 逻辑px），点「同步」→ 同步条出现，互斥成立。
  - 字号真的作用于渲染：行高（墨迹带中心间距）实测 57.4 / 60.4 / 63.3，与
    `size*2.9+14`（15/16/17px）逐档吻合；同时可见行数 11→9 重算正确；A- 回落、收起后恢复 11 行。
  - 同步真的移动高亮行：点「延后 1s」后，各文字带墨迹量序列整体平移一行（idx5–12 数值逐一对应），
    即高亮行由 index 9 变为 8。
  - 证据：`settings_probe_font_open.png`、`settings_probe_sync_open.png`、`settings_probe_font_18.png`，
    日志 `lyric_settings_probe.log`。
